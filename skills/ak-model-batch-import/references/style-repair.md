# 当前项目的体素风格修复标准

## 先识别真实问题

目标是大头、简洁硬边的体素 Q 版。实际用户参考图优先；不要仅凭“顶点少”或测试通过判定合格。旧批次的削角八边柱、解剖式肘部隆起、尖细小腿及独立指头是常见缺陷，不是每个模型都有。

- **直臂**：静止 A pose 从肩到腕中心线共线、方形截面、边缘笔直，不能仅把八边截面改四边却保留弯曲路径。按现有肩/腕确定向量，使用统一局部正交坐标。保留纵向分段以便蒙皮弯肘；肘骨位置须位于新中心线，更新权重阈值与绑定参考。运动时自然弯肘允许。
- **手**：先按下方严重程度决定是否修，不能因为存在手指、指缝或小拇指凸起就自动修改。确需修正时使用简洁块状手，保留手套面板、扣件、铆钉及左右差异。
- **腿**：避免削角肌肉轮廓、锥形竹竿小腿和夸张膝节。优先方形近等粗截面，与短裤、鞋靴衔接；只有参考明显要求时调整长度，不能把某一角色缩腿比例套给整个批次。腿变动必须检查髋/膝/踝、脚底高度、衣摆及动态锚点。
- **袖子**：布料可以宽大、外扩，但轮廓应为明确方块或几何布片，不能像膨胀二头肌。保留花纹、空袖内衬、开口与飘袖；不要把服装设计全部拉成贴身直筒。
- **手套/腕带**：手、护臂、袖口、手环用同一局部坐标和轴向。外包截面必须包住内部几何；闭合腕环要有前后左右四面，不能只做正面装饰。四面看无露皮、缺口、漂浮，关节适当重叠。左右非对称红手套/裸手等设定保留，不能把裸手误涂成手套。

## 实施中的易错点

不要用全局字符串替换所有 sweep/tube：腿、头饰、尾巴和服装可能共用生成器。按部件名或显式参数只改变目标。四边环的侧面、封口、内衬和索引循环都必须随顶点数变化，检查面朝向。配件不能用不同的旧弯曲路径再简单平移；统一局部坐标重建比逐点剪切可靠。几何变换后更新法线和包围盒。

直臂正确不代表配件同步正确：历史修订曾仅按全局 y 改 x，导致旧护臂侧面露肤；这种剪切或平移不能作为包覆证明。

直臂增粗会遮住原本贴在八边截面上的红丝带或花纹：重新定位到新表面外侧。袖口、鞋口、腕带也要留出包覆厚度。不同绑定骨之间的静态重叠不保证动作时闭合，实际检查弯肘和转腕。

保留源码与原 GLB，生成修订副本。对未改部件比较 position/normal/color/index accessor 数据，记录允许变更的部件名；骨架修订时区分几何变化与蒙皮变化。头部或身体高度变化时同步眼睛表情偏移与动态锚点。不能只改静态 GLB 而漏掉运行时内嵌 GLB。

可参考用户项目中已有修订实现，但先看其 `REVISION.md`：目录名不一定代表内容版本。历史根目录 `revise-*` / `publish-*` / `sync-*` 脚本写死批次与备份，不能直接重跑或当通用导入器。

## 用户确认的手部修复阈值（优先于统一方手偏好）

判断时打开这些原始用户截图，结合待处理模型的正面及斜侧面，按相近显示尺度比较。不要只统计手指数量或用是否存在独立指头判定。

| 手部程度 | 手臂正常 | 手臂存在弯曲轮廓、肌肉化或不合风格等问题 |
| --- | --- | --- |
| 轻度，图一、二水平 | 保留手部 | 必须修手臂；轻度手部仍可保留，仅做必要衔接和包覆调整 |
| 临界，图三、四水平 | 保留手部，不为统一而修 | 必须修手臂，并一起修正临界手部及腕部衔接 |
| 明显比图三、四严重 | 必须修手部 | 手臂与手部都修 |

这些图用于容忍度标尺，不是本次需要修改的四个模型。轻度/临界且保留的项目记为 `accepted_unchanged`，记录 `hand_severity`、`arm_issue` 和判断依据，不标为待修或失败。检查不清楚时先补渲染视角；临界边缘优先保留，避免过度修复。手套缺面、明显穿出、漂浮或断开仍属于独立的包覆/绑定缺陷，不能因手指程度可接受而忽略。此规则用于后续批次，不自动回滚以前已完成的修订。
