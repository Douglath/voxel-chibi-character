# 验证与交付

构建后回读实际 GLB，查看正侧背斜视、绑定姿态、Idle、Rig_Test，并测试暂停/恢复、循环和附加动态。数值通过不等于全身无碰撞；未观察项记录 unverified。

## 道具范围验收

将 scopeReview 与实际静态/骨骼 GLB、预览正侧背斜视逐项比对：排除项及其专用支架、带子、残留骨骼和动态不得重新出现，手部默认空置。明确获准保留的道具按记录验收；发饰和服装扣具等保留项不能被误删。几何可能合并到角色网格，不能仅搜索对象名称判断通过。参考图已清理或构件测试通过不替代模型检查，未观察项标 unverified。

## 按变更选测试

- 新角色/换色：眼白、高光、虹膜与服装独立，在实际正面检查虹膜中部原基色、克制的上下明暗及白色高光；很小或无分层虹膜按角色设计验收。服装检查部件内部低对比宽明暗面；头发按 hair.md 分别检查接界连续性、内部发束对比与鬓发几何区分。
- test-character.mjs：实际骨链响应、停止收敛、眼睛高光。
- test-refined.mjs：30/60/144 FPS 所有附加链有实际蒙皮权重、非零有限响应、固定挂点、收敛与瞬移恢复。
- test-tail.mjs：尾根、重力下落、局部碰撞采样；test-chest-ribbon.mjs：带子固定段实际连接、允许方向与衣身间隙。
- test-drop.mjs：共用 DropMotion，三高度×掉落/跳下×三帧率的18组冲击测试。说明直接落地制动的限制。
- test-head-closure.mjs、test-knees.mjs：下巴底面、膝盖正确屈曲。预览还有105姿态的袖口根端覆盖检查，非整件衣物碰撞。
- test-physics.mjs：扰动、碰撞约束与多帧率回归。按照新角色调整采样、部件名和尺度，不照搬当前狼耳少女的绝对坐标。
- 兽耳/尾巴/带状物按 ears-tails-straps.md，分别报告几何连接、运动、穿插、闪烁与生命周期。静态部件不要求非零响应。
- 组合配件按 accessories.md 检查实际连接与开孔、硬件保形、固定段/双端接触、自由段回弹及相关身体动作。正常预览距离确认身份可读，局部近景确认结构；骨骼父级正确或构件包测试通过不能替代当前角色实际 GLB 的检查。

合并/删除部件后同步几何、骨架、权重、动态链与测试；测试无关时明确范围，不能删除失败断言伪称验证完成。示例里只保留当前角色相关测试；裙子、蝴蝶结等新结构需要新的适用采样。

配色改动同时比较实际几何统计：已有面重着色可以保持拓扑，greedy 色界分裂则可能增加顶点和面。静态与骨骼导出都回读颜色；正常观看尺度检验层次，近景排查接缝、高光污染与过亮色块。源码 RGB 不能替代实际导出模型的可视检查。

## 服装层间与闪烁专项

- 修改衣摆、裤宽、厚度或绑定后，点名检查相邻部件对（如左右衣片—短裤），同时检查共面/近共面面片与实际相交。两个独立网格采用同一侧面坐标即是风险，即便根固定、衣摆长度、普通动态测试全部通过。
- 回读实际 GLB，记录内外层位置、静止间隙与权重差异。检查绑定姿态、待机、关节测试、实际跑动及相关躯干转动；数值检查实际蒙皮表面/三角形，不仅骨尖或包围盒，报告采样数、容差和距离指标的准确含义。
- 几何不相交、没有共面与视觉无闪烁是不同检查项；并行/近共面三角形不能只靠一项射线相交计数判定。浮点蒙皮使近乎平行的射线可能数值不稳定，命中点须确实位于有限三角形内；用间隙/距离复核，不能靠放宽失败阈值掩盖问题。
- 浏览器在正、侧、背、斜视和运动中检查黑白交替、条纹、穿出与接缝断开；未观察的项标 unverified。有限姿态的零相交不能宣称任意动作或完整自碰撞安全。
- 局部迭代保存可恢复版，对比未授权修改的网格/配色/权重是否保持；报告和截图绑定当前产物哈希。设计语义改变时新增或有依据地修订测试并说明旧断言为何过时，不让历史 PASS 混作当前证据。

## 交付和维护

交付源码、Three.js 0.180.0依赖、静态/骨骼GLB、多视图、预览、动态选择及参数、实际统计和限制。GLB只内嵌基础动画；附加动态需要 hair-physics.mjs 与 tail-dynamics.mjs，跑动/拖动需要 motion-demo.mjs，掉落需要 drop-demo.mjs。使用通用配件时一并交付 accessories 实现规格及其构件/运行时代码。未验证其他引擎自动恢复物理。

仓库根运行 `node scripts/verify-examples.mjs`，验证母版重建、改名脚手架和相关回归；运行 skill-creator 的 quick_validate.py 检查入口。证据图片来自实际浏览器，不把旧报告当新验证。当前母版完整自碰撞、多角色压力、其他引擎均未验证。

## 表情模板验收

按 [表情模板](expressions.md) 运行 test-expressions.mjs，检查八预设、独立符号、换色隔离、Normal 自动眨眼、暂停/恢复及离开普通模式时复位。浏览器观察半闭时上眼皮落下、高光被遮挡、闭合眼线平直且一像素粗，不能混入笑眼。GLB 未嵌入表情系统，交付 expressions.mjs 与 runtime 控件；表情几何和 draw calls 另行计数。
