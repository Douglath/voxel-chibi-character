# 渐进验证与交付

本文件统一决定检查时机与范围；专题文档说明实现和检查方法，不要求每次构建重跑全部测试。先按入口选择 delivery.mode；preview 只执行下一节，其余章节用于正式流程。静态成品仍按实际交付范围验收，不等于快速稿。

## 快速预览范围

- **完成条件：**生成或修改本轮要求的真实模型，保留可继续编辑的源码或模型副本，输出静态 GLB（或现有骨骼模型的固定姿态）及三张模型截图。默认正面、侧面、背面；诊断露肩等局部问题时可将其中一张换成斜视。三图使用同一版本、固定姿态和可比尺度，不另生图片代替模型截图。
- **只做最低检查：**实际文件能导出、载入和显示，画面不空白、不裁掉关注部位；查看轮廓、发型分组、服装层次、当前修改处及道具范围。顺手修明显影响判断的缺面或穿出，不做自动碰撞/穿插扫描。仅对所用导出路径检查必要数据；静态导出不要求先完成权重。
- **暂缓内容：**完整绑定适配、八表情/眨眼、基础动作及附加动态、动作穿插、生命周期、多帧率、掉落与全身碰撞。原有可用骨架或固定表情可复用，暂缓不等于删除；保持足以判断设计的发型、服装大形和层次，不退化为无特征占位盒。
- **最短执行：**已有工程直接改本轮问题；新工程用 `scaffold.mjs ... --preview`。脚手架源码工程修改几何后执行 `node character/export.mjs`，启动服务并打开 `/character/index.html`；仅有 GLB 时使用其实际编辑、导出与渲染路径，不为套命令重建无关工程。不为静态稿运行 rig-export 或默认离线 HTML 打包。当前静态导出器不应用网格变换，调整站姿须烘焙到几何或复用已有骨架固定姿态。截图从实际交付版本取得。
- **控制开销：**批量完成相关修改，截图后以本轮可评审为停止条件，不自动继续精修。已有静态页生成四个视角时选三张交付即可，不为少一张重写渲染器。缺少真实渲染能力时说明限制，不能仅凭导出成功声称完成三视图；不加载无关专题、不逐轮生成全套报告或统计。
- **简短交付：**标明“外形预览，功能未验收”，给三视图、实际模型/源码位置，并简述改动及暂缓范围。spec 记录 delivery.mode=preview 与待补项；模板自带报告或旧动态通过记录不作为本轮验收。
- **转成品：**用户要求继续完成时，保留已认可外形，把 delivery.mode 改为 final，恢复其要求的构建、表情及动态范围，再执行后文相关验收。快速稿的 autoBlink=false、requiredByDefault=false 等暂缓值不构成用户永久静态偏好；未明确禁用动态时恢复默认轻量，不重生参考或重做已认可模型。

## 检查节奏

| 阶段 | 必要检查 |
|---|---|
| 开工一次 | 查看参考，记录服装结构、保留/排除部件（scopeReview）及动态模式。需求未变时沿用，不反复分析同一参考。 |
| 外形迭代 | 一批相关修改后查看改动处及必要视角，确认能显示、连接与轮廓正常。几何、骨架或导出依赖变化后立即做廉价构建完整性检查：能导出/载入、索引和权重有效、数值有限；暂不跑长动作与碰撞采样。 |
| 外形稳定 | 适配骨架、表情和动态，对实际受影响功能执行下表专项；相关结构与参数稳定后再做多帧率、强扰动或碰撞采样。 |
| 最终交付 | 对最新实际导出物做一次整体验收，包含下节基础范围及已选模式要求；已通过且相关依赖未变的专项可复用证据。 |
| 验收后修改 | 只重测失效项并回读最新导出物、更新相关预览；新问题才扩大范围，不重跑未改模块。 |

普通外形迭代不逐轮执行全动作、八表情、多帧率、掉落、碰撞扫描或长报告，也不按固定轮数全测。相同会话已读规则无需反复加载。测试成功只汇总范围与结果，失败才展开相关日志；保存少量能说明改动的截图。未执行项标待验收，能力受限而无法验证的项标 unverified。

## 最终整体范围

- 回读当前静态/骨骼 GLB，浏览器查看正、侧、背、斜视与绑定姿态，确认轮廓、层次、颜色、接合、道具范围；不以源码 RGB 或骨骼父级正确替代实际画面。
- 动态版观察 Idle、适用的 Rig_Test/实际动作，以及所选附加动态的可见响应、停止收敛、暂停/恢复、循环与开关复位。静态部件无需非零响应，相机环绕不等于角色受力。
- 复用成熟表情模板时检查当前角色虹膜/眼白/高光、Normal 眨眼和代表性表情切换及控件。完整预设与专用回归按下表触发。
- 完整精修覆盖每个选中活动部件：待机、转向、轻推和适用跑动、组合运动接触、停止收敛、暂停/恢复、关闭复位/重新启用、瞬移与长停顿恢复，并完成 30/60/144 FPS 稳定性验证。此范围在动态稳定后集中完成，不随每轮造型修改重复。

将 scopeReview 与实际模型逐项比对：排除项及其专用支架、带子、残留骨骼和动态不得出现，手部默认空置；获准道具按记录验收，保留的发饰和服装扣具不得误删。几何可能合并，不能仅搜索对象名判断。参考图已清理或构件测试通过不替代模型验收。

## 按影响选择专项

脚本是现成检查工具，不是每个角色必跑的清单；使用前适配当前部件、尺度和采样，不能照搬母版绝对坐标。

| 变更/范围 | 对应检查 |
|---|---|
| 换色、花纹 | 查看实际导出颜色与正常尺度层次；眼白/高光不受服装色污染。已有面重着色可保持拓扑，greedy 色界分裂可能改变顶点/面数，按实际导出统计。无需重跑骨链或掉落。 |
| 头发/衣物几何、绑定 | 查看接界、固定点、层间间隙；结构稳定后检查受影响动作。头发方法见 hair.md；新裙摆等须使用适用采样。下巴/膝盖改动才用 test-head-closure.mjs、test-knees.mjs。 |
| 骨链、权重、动态参数/实现 | test-character.mjs 检查实际响应与停止收敛；按影响用 test-physics.mjs 检查扰动、局部约束和帧率。完整精修用 test-refined.mjs 覆盖实际权重、固定挂点、有限响应、收敛及瞬移恢复；轻量角色只有时间积分/生命周期变更或帧率相关问题时扩大到多帧率。 |
| 尾巴、带状物、组合配件 | 按 ears-tails-straps.md、accessories.md 检查连接、开孔、硬件保形、活动空间及相关身体动作；适用时用 test-tail.mjs、test-chest-ribbon.mjs。静态配件只查结构。 |
| 掉落/强扰动 | 完整精修或用户要求掉落、跳下、强扰动时按 drop-testing.md；轻量模式只在其实际运动范围需要时选用。test-drop.mjs 复用生产 DropMotion，三高度 × 掉落/跳下 × 三帧率，共 18 组；参数/集成稳定后执行。 |
| 前进跑动/持续风阻 | 用户要求或本轮接入、修改该驱动时，复用实际运行的轨迹与受力代码，覆盖加速、匀速、急停、收敛；采样受影响蒙皮的响应上下限及接触。首次接入或修改持续驱动时用同轨迹开/关驱动对照，区分风阻与惯性；浏览器实际观察头发/衣摆后扬，原地步态或相机移动不代替前进。生命周期与帧率按动态模式复用上文要求，不另设全身复测。 |
| 表情模板、眼部坐标/头型、接入或眨眼实现 | 按 expressions.md 用 test-expressions.mjs 验证八预设、独立层、换色隔离、挂接及眨眼生命周期；其多帧率检查随该专项执行。只改虹膜色且模板/接入未变时查看颜色与眨眼即可。 |

合并/删除部件须同步几何、骨架、权重、动态链与对应测试。无关测试不运行；失败断言不能通过删除或放宽阈值伪装通过。设计语义变化时说明旧断言失效原因，再修订受影响检查。

## 层间穿插与闪烁专项

在衣摆、裤宽、厚度、绑定或活动范围变化且存在相邻层风险时执行：

- 点名相邻部件对，回读实际 GLB 的内外层位置、静止间隙与权重；独立网格侧面坐标相同可能共面。检查绑定姿态、待机和受影响动作/转动，不无差别扫描全部动作。
- 数值采样针对实际蒙皮表面/三角形，不能仅查骨尖或包围盒。记录采样、容差和指标含义；有限三角形命中与间隙/距离交叉复核，近乎平行射线可能不稳定。
- 项链、细带等可能整体埋入承载体，表面零交叉不证明安全。疑似此类问题时，对相关部件实际顶点/面内点补内部包含检查；明确目标是否为封闭体，开口壳体或不稳定射线结果须另作局部表面与视觉核对，不能直接判通过。合法固定端接触、隐藏发根嵌入与可见穿入分别记录；例外限定到有依据的连接区域，不豁免整类配件或整个身体。
- 几何相交、共面与视觉闪烁分别判断。浏览器在必要视角及运动中观察条纹、穿出、断接；零相交不证明无闪烁。袖口的 105 姿态覆盖检查也不代表整件衣物碰撞安全。

数值通过不等于全身无碰撞；只声明观察/采样范围，不宣称任意动作或完整自碰撞安全。

## 证据与交付

用一份简短记录标明测试范围、产物版本及相关改动（如飘带几何/权重、动态代码），有需要且有能力时记录哈希，不建立逐文件依赖清单或每轮全量对比。相关依赖未变的历史专项可继续引用，标明原测试版本及为何适用，不伪称对新版本重跑；有关几何、骨架、权重、运行时或导出变化使对应证据失效。最终整体检查和更新的截图必须来自最新产物；无法计算哈希时使用明确版本，不编造哈希。

交付源码、Three.js 0.180.0 依赖、约定的静态/骨骼 GLB、多视图、可运行预览、动态选择/参数、实际统计及限制。GLB 只内嵌基础动画；按所选功能附带 hair-physics.mjs、tail-dynamics.mjs、motion-demo.mjs、drop-demo.mjs、expressions.mjs 及相关控件。通用配件附实现规格与代码。表情几何/draw calls 单独计数；Node 耗时不当浏览器帧率保证，其他引擎恢复物理需另行验证。

`node scripts/verify-examples.mjs` 的母版重建/脚手架回归，以及 skill-creator 的 `quick_validate.py`，仅用于维护 skill 或母版。普通角色制作不执行；维护时也只扩展到改动影响的验证。母版完整自碰撞、多角色压力及其他引擎尚未验证。
