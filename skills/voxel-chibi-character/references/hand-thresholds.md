# 手部分级标尺

此标尺仅决定手部保留或修复；静态臂、腿与配件另按 [造型规则](modeling.md#静态肢体与手部) 判断。四图随独立包提供，无需额外附件或本地导入 skill。


判断时打开这些原始用户截图，结合待处理模型的正面及斜侧面，按相近显示尺度比较。不要只统计手指数量或用是否存在独立指头判定。

| 手部程度 | 手臂正常 | 手臂存在弯曲轮廓、肌肉化或不合风格等问题 |
| --- | --- | --- |
| 轻度，图一、二水平 | 保留手部 | 必须修手臂；轻度手部仍可保留，仅做必要衔接和包覆调整 |
| 临界，图三、四水平 | 保留手部，不为统一而修 | 必须修手臂，并一起修正临界手部及腕部衔接 |
| 明显比图三、四严重 | 必须修手部 | 手臂与手部都修 |

- [图二：可接受](hand-thresholds/example-2.png)
- [图三：临界，手臂无问题则保留](hand-thresholds/example-3.png)

这些图用于容忍度标尺，不是本次需要修改的四个模型。轻度/临界且保留的项目记为 `accepted_unchanged`，记录 `hand_severity`、`arm_issue` 和判断依据，不标为待修或失败。检查不清楚时先补渲染视角；临界边缘优先保留，避免过度修复。手套缺面、明显穿出、漂浮或断开仍属于独立的包覆/绑定缺陷，不能因手指程度可接受而忽略。此规则用于后续批次，不自动回滚以前已完成的修订。
