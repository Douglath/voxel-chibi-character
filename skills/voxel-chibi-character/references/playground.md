# 固定离线游乐场

assets/playground/model-playground.html 是固定空模板，源码在同目录。支持批量 HTML/GLB 导入、表格、角色点击、漫游和统一单人测试；保留观察台、小花园、暮色庭院、香港街头及自定义场景。新模板默认观察台，保存后恢复保存时场景；单人场景同步主题，随机表情按钮立即播放。

## 保留角色原有动态

以当前用户认可的效果为准：保留角色自己的头发、衣摆、尾巴及饰品物理模块、参数、约束和已实现的碰撞。无需统一动态格式，不按骨骼名字猜测一组通用弹簧参数来替换原动态。单人和多人均调用同一套角色求解器，不自动降级。运行时动态不烘焙到 GLB；不把未实现的完整布料或碰撞声称为现有功能。

正式项目运行 scripts/build_html.py，生成固定游乐场和同目录 *-dynamics.html 专用页。scripts/build_playground.py 从明确生成的源工程预览中打包原始 hair-physics、tail-dynamics、accessory-dynamics 模块；不支持的依赖应明确报错并适配，不悄悄改成通用动态。专用页用于保留完整专项测试，不是固定游乐场减配的理由。

静态项目可运行 python scripts/build_playground.py --glb character/<id>.glb --output character.html --title 角色名；已有离线源预览可用 --source-html。静态交付不补造骨骼或动态。保留已有 standardPhysics 数据的读取兼容，但它不是新角色默认输出格式，也不据此覆盖原动态。

## 跨 HTML 导入

网页导入器仅运行随模板已核对的物理模块，不执行陌生 HTML 的任意脚本。现有注册角色可直接批量导入。新角色在自己 HTML 中包含模块，不代表另一个旧 HTML 已认识它：交付跨文件导入时，须把经核对的角色求解器及依赖加入接收模板注册表，再验证批量导入与保存重开。仅传递模块编号不足以迁移新模块；不得以替换成简化弹簧解决。尚未适配的模块要明确提示并保留专用原动态页，不声称跨页面完整保留已完成。

所有生成脸部仍须无嘴，不在导入器里任意删除陌生模型的结构。首次单模型打开进入单人测试，可返回大厅；集合保存为独立 HTML，角色数据及已注册运行模块一起保留。

## 控制与验收

大厅显著显示 FPS、毫秒/帧、当前人数与物理人数，旁边提供“物理动态：开/关”。关闭停止附加物理并复位，保留走动、眨眼、表情及单角色开关偏好。全局开关随集合保存。性能对比保持同人数、场景、视角及播放状态；FPS 受设备和刷新率限制。

求解在原模型单位下运行，显示缩放不改变弹簧长度与碰撞半径；固定 1/120 秒推进。实际验证单人及多人跑动、扰动、开关、暂停和切换复位。涉及打包或导入的更改时，用两个角色 HTML 实际批量拖入目标模板，验证原角色模块及动态响应，保存重开再检查；不能只验证源页面。新角色须与其原动态页对照，不以“有晃动”代替效果保留验收。
