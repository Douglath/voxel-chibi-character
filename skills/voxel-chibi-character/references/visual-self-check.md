# 当前角色的风格参考与外形自检

这是原建模流程的补充自检模块，不替换母版、建模专题、交付模式或动态实现。检查时机仍由 [validation.md](validation.md) 决定；利用已有模型截图和预览，不另开一轮制作流程，也不因本清单增加全量测试。

## 先看完整角色，再看本轮局部

对照本角色原图、有效四视图和用户已认可的当前版本，在相近视角和显示尺度下观察实际模型。先判断整体是否仍保留原 Skill 的精细体素风格与人物设计，再判断指定部件是否修好。局部组件正确不能抵消全身细节退化；不要把独立试做稿或技术通过记录当作认可样例。

体素化改变表达方式，不授权删去可辨认的服装设计。按当前参考检查实际存在的内容：

- **衣服结构与细节**：领口、露肩关系、裁片、内外层、褶边、袖型/袖口、裙褶及花纹是否仍能辨认；不能把有结构的衣装概括成几块无层次的方块。胸前衣物的分色、独立肩带、连接带和扣件不能被一个厚方体吞并；侧视确认胸衣在外套里面的前后关系，而不是只在方块表面补颜色。
- **透明区域与内构**：仅在参考或用户要求透明时，检查实际画面能否透过外层看清应有内衣/结构、露肤区和分层；设置透明度不代表效果成立。不能为了显露内部而任意去掉外层、改变领口或露肩设计。
- **腿部与附着物**：腿环、绑带、交叉带、袜口、鞋带/鞋扣是否保留位置、走向、包覆关系和配色；不能因体素化、改腿型或缩放而丢失。
- **身份饰件**：关键扣具、胸饰、帽饰是否保留形状、主色与组成，在参考应见的视角可见；红色心形不能只剩银色颗粒或普通方扣。
- **相邻层次**：颈圈、蝴蝶结、结心和垂带等是否能从轮廓、前后关系及材质表现区分；网格分开不等于画面分清。

只检查参考中有的部件，不按示例给其他角色补造饰件。小到无法辨认的纹样可按原专题概括；可辨的结构或标志物不能直接省掉。发现整体简化或细节丢失，先修本角色受影响部位，不能以“体素风格”解释掉偏差。无需新增逐件 JSON 或长报告，沿用已有工程状态记录必要问题即可。

## 细带、扣具与裁片：防止风格纠正过头

以下是对原专题实现结果的检查，不重新规定建模算法。按部件类型回到 [服装](garments.md)、[带状物](ears-tails-straps.md) 和 [配件](accessories.md) 的已有方法，不能把所有细节统一栅格化，也不能全部改成无厚度的连续薄片。

| 当前参考中的部件 | 实际模型上要保留的关系 |
|---|---|
| 贴身皮带、肩带 | 起点、经过点、穿扣位置与末端可追踪，宽厚稳定，贴合承载物而非碎成散块 |
| 悬垂飘带 | 固定端与自由端清楚，块状厚度及少量转折连续，不能变成纸片或断续珠串 |
| 框扣、连接环、五金扣 | 参考需要的开孔和穿带空间仍存在，保留标志轮廓；不能用实心黑块填孔 |
| 衣领与倾斜裁片 | 露肤区、前后层次、硬边和必要厚度成立，不退化为胸前厚盒 |
| 小图案与纹样 | 在正常观看尺度保留主要辨识信息，概括微细纹样不能同时删除承担连接作用的结构 |

在正常观看尺度看是否可辨，必要时补一个局部侧/斜视，确认细孔未堵、带子未断、内构未被遮没。检查只针对当前涉及部件；构造示例存在或技术测试通过不能替代实际画面。

## 特定结构的局部复核

- **侧发与后发**：用下颌、颈根、衣领等参考地标检查发尾长度、颈部覆盖和前后厚度，不能只凭“短发”类别决定尺寸。参考要求侧后发厚、垂到领口时，仅加宽正面轮廓或加厚面前鬓角不能替代侧后体积；从侧/背或斜视确认，不把本例发长推广为所有短发标准。
- **机械/悬浮头饰**：检查头饰、底座、耳片和头发之间的相对位置与设计间隙；视觉独立和运动跟随分开判断。参考是悬浮结构时，不补造与头部相连的支架。若设计要求底座在悬浮耳根正下方，为露出底座而把它移到额头正前方仍是错误。按已选动态观察整体扰动与间隙，不仅确认节点存在。
- **螺旋马尾**：检查发量、连续绕转、卷层厚度、收束和根部连接；不要只凭“几何沿螺旋路径排列”判通过。珠串、薄弹簧、叠盘或无发量的细带不能冒充参考中的宽厚卷发。
- **倾斜帽子、光环等刚性部件**：局部形状先成立，再整体旋转/放置；检查倾斜是否错误引入世界坐标台阶。局部像素轮廓允许保留，但不对整体旋转后的顶点重新取整。帽子与其帽带/扣件一起保持姿态。
- **组件装配**：即使复用了认可部件，也要在当前完整角色上看比例、根部、遮挡和接触。帽带/扣件埋进头发、共面条纹、悬浮根部等仍是不合格；不能因组件自身通过检查而跳过接合判断。
- **比例**：翅膀、帽子、卷发等相对头宽、肩宽和身体的关系是否符合当前参考/用户纠正；缩小一个部件不能同时丢失其轮廓组织。
- **已选动态**：按原动态模式，实际观察跑动与停止时自由端是否呈现预期响应、刚性饰件是否保形。只看“有非零位移”或按钮可用不能证明动态效果；本项不新增强风、多帧率或全身碰撞扫描。

## 局部修正后，复查必须保留的关系

沿用原有 `changed / preserved / affected` 记录，简记本次改变什么、必须保留什么空间/造型关系、哪些相邻部件受影响，不新建另一套表。可见性、位置正确性和连接关系要同时成立；不能为修一项而破坏另一项。

例如修头饰被遮挡：保留它与耳根/底座的参考关系，复查头发覆盖、悬浮间隙和侧视位置；修侧发厚度：保留已认可的面前鬓角薄度及发尾长度；修服装风格：保留已认可的内外层、开孔、带子路径与露肤区。优先做满足这些关系的局部调整，不默认把整个配件前移、把全部附件重新栅格化或重做整件衣服。

分别判断参考关系、体素风格和功能是否成立。前两项仍有明显问题时，不用导出/绑定/动态测试通过作补偿，也不继续扩大功能验证来替代修正；仍遵循原 validation.md 的检查时机与范围。

## 风格参考的使用范围

母版和原有专题继续决定通用风格。遇到相近宽厚卷发、贝雷帽或光环时，可查看 [岁己 V4 局部风格样例与可选组件](approved-parts.md)：其中包含认可版完整角色及局部正/侧/斜视，供判断细节密度、发量和局部成形方式。组件是可选工具，不要求替换当前正确实现，不自动复制进脚手架；颜色、尺寸和人物饰件不推广为全局标准。

先用完整角色参考避免“局部对了、衣服全丢了”，再用局部图诊断具体构造。参考图与技术组件不自动授予新角色的外观认可。

## 检查边界与停止条件

只读当前角色、Skill 随包参考及用户明确指定的参考，不访问其他角色或扫描资料库。回链数据库仅确认当前角色的模型版本、入口及认可状态正确，不运行全库 overview/catalog、verify、媒体哈希或全量测试。

沿用原流程的完成条件：明显偏差先自主修正；用户审美取舍保留待评审。每次只复核变化和受影响部位；已有相关检查不重复执行。整体风格或关键细节退化时不得以局部通过宣布合格，也不擅自重构 Skill 或重做未受影响的角色内容。
