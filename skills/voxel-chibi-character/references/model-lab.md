# 多模型与交互验收（按需）

用户需要多模型显示、导入或共同测试时，复用 assets/model-lab。包内只引用唯一银灰狼耳少女母版，默认加载两个独立实例；其他角色由用户导入。不要重新打包旧角色作为风格模板。

```powershell
node <skill目录>/scripts/scaffold-lab.mjs <新目录> <端口>
```

复制后的工程复用兼容 Three.js 依赖或运行 npm install，再 npm start。新增专用动态角色时，在 lab.mjs 的 catalog 注册 GLB 与对应物理类；不能只凭相似文件名把银灰狼耳少女骨链套到任意导入模型。

## 交互与导入

- 默认 OrbitControls 环绕镜头，极角约0–π，可看头顶、裙内、足底；不要把上下拖动映射为仅±0.25弧度的角色倾斜，然后称作自由观察。
- “甩动角色”独立模式：左右转身、上下有限俯仰以触发惯性；提示与按钮状态匹配。转镜头本身不应产生发裙惯性。
- 提供正侧背、头顶、足底、聚焦选中、显示全部。底部观察不放实体地板挡住；网格可关闭。
- GLB多选/拖放；glTF同时选.bin及纹理。用LoadingManager解析所选本地资源，缺资源明确报错；文件名冲突需改名或使用路径。文件只读入浏览器，不上传、不默认持久保存。
- 外部模型只播放自带动画，无动画则静态显示；不自动增加专用物理。模板未提供Draco/KTX2/Meshopt解码器，不能宣传全格式兼容。

## 实例隔离与性能

- 每实例独立骨架、mixer、动作状态和物理粒子；可独立加载GLB，或用SkeletonUtils.clone。不能只用普通Object3D.clone共享蒙皮状态。
- 物理碰撞代理随实例世界变换更新；排列模型、瞬移、恢复显示后重置粒子。不能把躯干胶囊留在场景原点。不同实例暂不互相碰撞。
- 暂停、隐藏、关闭物理需停止相应计算；删除释放几何、材质、纹理、骨架并清理mixer。骨架辅助线在正确世界坐标下显示，不能重复叠加排列父节点变换。
- 观察真实draw calls、渲染面数、FPS；材质相同仍可能每网格一个draw call。短时少量实例流畅不是多人游戏性能保证。

## 验证

实际选择文件验证GLB及glTF+.bin导入、动画选项、删除与缺资源提示；不能只验证按钮存在。多个实例同时播放，单个暂停/骨架开关不串扰。上下拖动从头顶连续转到下方，不能仅验证快捷按钮。当前项目页面实测过5实例及本地导入；新脚手架或新角色仍需在目标页面复核。
