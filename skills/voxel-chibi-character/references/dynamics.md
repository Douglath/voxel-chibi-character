# 动态选择、强度与成本

本节用于正式流程；delivery.mode=preview 时按 [快速预览范围](validation.md#快速预览范围) 暂缓功能，不将暂缓写成永久静态偏好。正式流程按用户要求选择范围；没有明确要求时使用轻量动态：

- **轻量（lightweight）**：基础动画与合适的附加动态，通常选 2–3 类、约 4–8 新骨，按角色实际活动部件调整。
- **精修（refined）**：用户要求精致动态、完整精修或所有合理部件动态时，按 [完整精修](refined-dynamics.md) 覆盖有合理自由度且能改善视觉效果的部件，不受轻量配额限制。
- **静态（static）**：用户明确静态/禁用动画时遵从该范围；若需真正无骨骼静态资产，导出时移除皮肤/骨架。

将所选模式记入 character-spec.json 的 dynamics.mode，并简记选择原因及选中/省略部件。仅说“精致外观”不自动扩大动态范围；用户的静态要求、指定部件或性能预算优先。无合理活动部件时解释原因，不强造软体或新饰件。

母版 20 基础骨 + 23 附加骨只是实例，23 不是目标数或上限。不添加参考里不存在的部件来用满预算。检查时机和模式验收统一见 [渐进验证](validation.md)，以下为实现约束。

## 当前范例参数

以下仅用于同尺度、同公式的起点；角度是上限，不是目标摆幅。

| 部件 | 刚度/阻尼 | 限角与结构 |
|---|---|---|
| 后发 | 左 62/11、右 68/12 | .24 rad；每侧两骨，根稳末端滞后 |
| 鬓发/侧发 | 165/22，辅助外发 95/15 | .075/.12 rad；连续发片共享兼容权重 |
| 耳朵 | 290/30 | .025 rad；每耳整体刚性微转 |
| 侧衣摆/后衣摆 | 130/19、155/21 | .08/.06 rad；腰部承载 |
| 袖下缘 | 125/19 | .075 rad；跟随前臂，非整袖软化 |
| 胸口飘带 | 105/17 | .14 rad；两骨、胸前左右平面摆动 |
| 尾巴 | 见 tail-dynamics.mjs | 三段重力角弹簧，骨盆尾根固定 |

短扣件、中结、帽冠、鞋、脸通常刚性。柔长发、布条、挺括耳饰应有不同响应；不全用同频正弦。参数和轴按实际结构修改，不照抄到帽子、辫子或披风。附加骨必须实际影响几何，不能只生成空骨。

## 稳定性与成本

- “轻一点、更飘逸”通常是有限的跟随、滞后和回弹，不等于接近水平飞起。从小幅参数逐步调整，分别设置驱动力、回正/重力、阻尼和限角，保留原默认姿态，除非用户要求改变它。
- 以实际蒙皮带尾的抬升量/自由段长度和侧面轮廓衡量强度，测试应同时有可见响应下限与过度抬升上限；不能只断言位移非零或大于某值。三段角度会累积，单骨限角不等于整条带的总后扬角。具体阈值按角色和用户要求选，不照搬一次修正的推力或角度。

- 固定步进 1/120 秒、限角、阻尼、长停顿/瞬移重置。模拟端也约束方向，骨骼转速受限；详见 drop-testing.md。运行时有重复矩阵更新和临时分配，不声称多角色已优化。
- 先减少无收益链，再实测投影次数与分配优化。几何发束合并不会自动减少骨骼或模拟成本。
- 关闭附加动态停止积分，显示约定的静止姿态；基础动画与 GPU 蒙皮仍存在。远景简化建议不代表已实现自动 LOD。
- 区分静态 GLB 与带骨骼/基础片段 GLB的差值、附加运行代码体积、CPU模拟、GPU蒙皮、绘制次数。物理关闭不减少下载体积。耗时只报告具体设备/环境实测，不将 Node CPU 测试当浏览器帧率保证。
- 母版仅局部端点/胶囊与角度约束；不是完整头发、衣服自碰撞。脚底没有 IK。
- 本坐标正面 +Z，小腿局部 +X 屈曲使足跟后移；其他骨轴需实际检查。跑动展示不等于成品步行动作。

先稳定造型和连接，再调动态；一批相关修改可以合并检查。拖动演示须改变角色变换，让生产代码响应实际受力。
