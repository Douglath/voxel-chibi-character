# 掉落与跳下测试

完整精修、多附加部件或用户要求强扰动时，复用母版 drop-demo.mjs 和 test-drop.mjs。轻量角色可按活动部件选择是否需要此测试，不自动扩展为成品跳跃系统。

- 使用同一 DropMotion 驱动浏览器与数值测试。角色根节点真实竖直加速，附加部件由生产物理响应，不能用预录摆动伪装受力。
- 当前范例：重力加速度 18 模型单位/秒²，低/中/高释放高度 3/6/10，跳下先给 3 单位/秒向上初速；不是米制参数，缩放或改步长后重新校准。
- 起点放置属于重置，不能把瞬移本身当落下冲量。提供掉落、跳下、慢放、全程/近看跟随、暂停恢复、结束复位。
- 固定 1/120 秒步进，比较 30/60/144 FPS。检查有限位置/旋转、实际蒙皮连接、根稳定、每步突变、落地后收敛；报告范围和阈值。
- 防爆甩要在积分/约束阶段限方向，而非只裁最后骨骼角；终端静止轴需使用已摆姿态的骨骼方向。必要时限制转速，避免限角两边来回跳变。
- 当前测试是落地直接制动，故意暴露冲击问题。没有完整落地动作、足底锁定或刚体接触；通过不等于完整网格自碰撞安全。
