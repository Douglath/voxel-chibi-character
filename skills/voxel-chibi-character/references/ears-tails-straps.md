# 兽耳、尾巴与绑带：构建和验收

角色含这些部件时读取。先依据参考和用户意图分类，再决定绑定与动态；不是每种耳朵、尾巴或带状物都应使用同一种弹簧。当前 scaffold 包含本角色的兽耳、尾巴与胸带实现；其他结构仍需按以下约束适配，不能认为范例自动覆盖所有附件。

## 共同连接要求

- 记录承载者、几何连接位置、固定段、过渡段、自由段、刚柔属性、允许的运动轴及相邻碰撞对象。没有自由段的部件不强行加摆动。
- 骨骼挂在正确父级、根部顶点不漂，不等于几何已经连接。静止和运动时都要从侧面/斜面确认固定端实际贴合或合理嵌入承载物，隐藏挂点需说明依据。
- 固定段随承载者，渐变权重从自由段开始；根部需要稳定的原有表面支撑。不同运动组保留必要接触面，不挖洞或删除承载表面来给附件让位。
- 防穿模时只为自由段留必要间隙，固定段可通过短过渡段连接。禁止把整件附件外移后，以“不穿模”掩盖悬浮；不靠加厚、双面材质或深度偏移遮盖重叠面闪烁。

## 兽耳

先区分生物耳、硬质耳饰和柔软垂耳。硬质耳饰可以固定或整体刚性微动；生物耳可用固定耳根与有限转动；柔软垂耳才按长度分段。微动幅度由形状和活动空间决定，不统一强制摇耳。

- 耳根连接头部或实际头饰承载物，不能只放在头发表面外侧。刚性耳全体顶点使用同一刚性变换；软耳保留固定根区，耳尖响应更柔。
- 检查与头皮、发帽和另一只耳朵的接触，限制向头内折入和不合理轴向扭转。不能用明显脱离头部的距离解决碰撞。
- 验收耳根接触、转头/轻推后的有限响应与回弹。刚性耳检查形状或顶点间距离保持；软耳检查根稳与弯曲连续。饰品耳不能被当成肉耳拉伸。

## 尾巴

先区分柔性长尾、短硬尾、机械尾及服装附尾，按实际承载者确定尾根。柔性尾通常接骨盆后方；服装附件跟随衣物承载点。不可为避开发丝把整条尾巴悬置在背后。

- 分清绑定姿态、静止展示姿态、重置演示。参考或用户要求“向后伸出再下垂”时，绑定沿角色后方伸直，动态施加重力后形成弯曲；不能只把向下的发链移到尾巴位置，也不能只靠回到绑定姿态的弹簧冒充重力。
- 柔性长尾可采用根部较硬、中段弯曲、末端较柔的少量连续骨段；尾尖回翘按设定选择，不作为所有尾巴的要求。骨数、长度、刚度和摆幅按角色调整。
- 几何沿尾长有足够分段，骨链方向与蒙皮一致，尾根真实连接且不随避碰修正平移。先建立连接，再用限幅和局部臀腿碰撞处理自由段；不要承诺完整头发/衣物自碰撞。
- 默认预览可预先稳定在静止姿态；需要观察下落时提供重置演示，明确关闭动态、重新启用和 T-pose 各显示什么姿态。
- 验收根部几何与蒙皮固定、起始伸出方向、重力下落、分段滞后、回弹收敛，以及跑动/转向下与臀腿及长发的接触。受力正确不能替代尾根连接正确。

## 绑带、发带与悬垂飘带

先区分：贴身绑带随承载物变形；刚性发带/扣件整体跟随挂点且不拉伸；悬垂飘带才有独立自由段。不要凭细长外观把拉链或固定装饰误作飘带；用户明确要求其飘动时按该设计调整。

- 悬垂带的上端或缝合段必须贴住衣服，固定段保持稳定，短过渡段衔接有间隙的自由段。不能仅将整条带刚性绑定胸骨、或整条向外移动，作为完成动态/连接的证据。
- 按位置和用户意图选择主要运动平面：胸前左右摆的带子以胸口局部左右方向为主，限制朝胸内运动与扭转；其他带子可使用不同方向。轴由实际模型坐标确定，不机械复制局部 Z 轴。
- 长带按长度分段并渐变权重，短硬扣件只绕真实挂点小幅转动。下方衣身表面完整；移除与带子重复的原始装饰几何，避免旧层仍在原位置闪烁。
- 验收固定段实际贴合、自由段沿所选方向有可见运动、对禁止方向的位移受限；检查整条带的厚度与衣身/衣摆间隙，不只检查骨尖。左右摆动和回弹通过后，仍要单独检查起始端。

## 验收与报告

针对实际导出 GLB、实际蒙皮和实际运行时逐项记录 pass / fail / unverified，不合并成笼统的“物理通过”：

1. **连接**：固定端几何接触承载物、运动中不脱离；骨骼父级与根顶点稳定另作检查。
2. **运动**：允许轴的响应非零且有限，受限轴符合设计；停止后收敛。静态部件检查保持稳定，不要求非零摆动。
3. **穿插**：同时运行头部、身体、四肢与附加动态，检查相关接触对；在正、侧、斜视下观察。数值采样说明动作、表面/端点范围和容差。
4. **闪烁**：检查重复几何、共面或近共面表面、缺失承载面及动态交替遮挡；无明显穿插不等于无闪烁。
5. **生命周期**：动态部件在 30/60/144 FPS 下测试扰动、停止、暂停恢复、关闭复位、重新启用、长停顿和瞬移；检查对应的静止姿态约定。

已有测试若只验证挂点或骨尖，补充实际蒙皮固定段/自由段与可见接触检查后才能覆盖连接验收。测试阈值按角色尺度设定，不照搬本轮角色的绝对坐标、骨数或间隙。浏览器未观察的项目标 unverified；只报告已验证动作范围，不宣称所有姿态无穿模。
