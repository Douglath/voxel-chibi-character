# 兽耳、尾巴与绑带：构建和验收

角色含这些部件时读取。先依据参考和用户意图分类，再决定绑定与动态；不是每种耳朵、尾巴或带状物都应使用同一种弹簧。当前 scaffold 包含本角色的兽耳、尾巴与胸带实现；其他结构仍需按以下约束适配，不能认为范例自动覆盖所有附件。

## 共同连接要求

- 记录承载者、几何连接位置、固定段、过渡段、自由段、刚柔属性、允许的运动轴及相邻碰撞对象。没有自由段的部件不强行加摆动。
- 骨骼挂在正确父级、根部顶点不漂，不等于几何已经连接。静止和运动时都要从侧面/斜面确认固定端实际贴合或合理嵌入承载物，隐藏挂点需说明依据。
- 固定段随承载者，渐变权重从自由段开始；根部需要稳定的原有表面支撑。不同运动组保留必要接触面，不挖洞或删除承载表面来给附件让位。
- 防穿模时只为自由段留必要间隙，固定段可通过短过渡段连接。禁止把整件附件外移后，以“不穿模”掩盖悬浮；不靠加厚、双面材质或深度偏移遮盖重叠面闪烁。

## 兽耳

先区分生物耳、硬质耳饰和柔软垂耳。硬质耳饰可以固定或整体刚性微动；生物耳可用固定耳根与有限转动；柔软垂耳才按长度分段。微动幅度由形状和活动空间决定，不统一强制摇耳。

- 耳根连接头部或实际头饰承载物，不能只放在头发表面外侧。刚性耳全体顶点使用同一刚性变换；软耳保留固定根区，耳尖响应更柔。
- 检查与头皮、发帽和另一只耳朵的接触，限制向头内折入和不合理轴向扭转。不能用明显脱离头部的距离解决碰撞。
- 验收耳根接触、转头/轻推后的有限响应与回弹。刚性耳检查形状或顶点间距离保持；软耳检查根稳与弯曲连续。饰品耳不能被当成肉耳拉伸。

### 耳部体积构造与局部返修

可查看 [杯状耳体素样例](../assets/hair-kit/parts.html)；它仅演示壳体与内凹，不提供角色适配或动态。

耳型先记录外轮廓、开口朝向、耳根位置、耳壳厚度、内耳深度，以及帽子/头发遮住哪部分。杯状或凹耳不能用平板贴一块内耳色替代，也不能仅把整片平板旋转就声称有凹度。

按外壳—内凹—耳缘—必要内耳毛组织少量大块面；像素轮廓在局部坐标建立，再按耳根整体旋转。耳毛来自参考，保留少数向外的短块，避免填满内凹或加成一圈齿轮。耳缘厚度、内凹深度与整体朝向分别可调；修内凹不自动放大耳朵，改耳向不顺带光滑化轮廓。

与帽子相交时按真实覆盖关系隐藏该部分，不强行让双耳全部显露。正面看辨识轮廓，侧/斜视看内凹与壳厚、耳根接入，遮挡视角确认帽子和发帽；动态只复测受改动影响的根部与耳壳保形。

## 尾巴

先区分柔性长尾、短硬尾、机械尾及服装附尾，按实际承载者确定尾根。柔性尾通常接骨盆后方；服装附件跟随衣物承载点。不可为避开发丝把整条尾巴悬置在背后。

- 分清绑定姿态、静止展示姿态、重置演示。参考或用户要求“向后伸出再下垂”时，绑定沿角色后方伸直，动态施加重力后形成弯曲；不能只把向下的发链移到尾巴位置，也不能只靠回到绑定姿态的弹簧冒充重力。
- 柔性长尾可采用根部较硬、中段弯曲、末端较柔的少量连续骨段；尾尖回翘按设定选择，不作为所有尾巴的要求。骨数、长度、刚度和摆幅按角色调整。
- 几何沿尾长有足够分段，骨链方向与蒙皮一致，尾根真实连接且不随避碰修正平移。先建立连接，再用限幅和局部臀腿碰撞处理自由段；不要承诺完整头发/衣物自碰撞。
- 默认预览可预先稳定在静止姿态；需要观察下落时提供重置演示，明确关闭动态、重新启用和 T-pose 各显示什么姿态。
- 验收根部几何与蒙皮固定、起始伸出方向、重力下落、分段滞后、回弹收敛，以及跑动/转向下与臀腿及长发的接触。受力正确不能替代尾根连接正确。

### 尾部形态与参数隔离

先记录尾根、中心路径、沿长度的截面宽/深、末端形态及毛簇走向。蓬松尾的体积来自主体截面和少数顺毛簇，不用一圈密集尖刺替代；机械尾保留关节和硬段，不沿用软尾压扁形变。

整体长度、蓬松程度、静止朝向、运动幅度是不同参数。用户要求“身体缩小、尾巴保持”时隔离缩放组并复核尾根；用户要求避开头部时优先改允许的静止朝向/限幅，不默认缩短已认可尾巴或把尾根移离骨盆。跑动中的滞后与横向/纵向响应须基于实际骨链轴向，不把更大周期摆幅当作更自然。

## 绑带、发带与悬垂飘带

像素形状遵循 modeling.md 的“像素表达与部件姿态”；不要从母版的薄长方体构件推导出“所有像素飘带都可用连续薄片”。用户指定像素外形时单独验收块状厚度、轮廓和端头；动态通过不能替代风格通过。

先区分：贴身绑带随承载物变形；刚性发带/扣件整体跟随挂点且不拉伸；悬垂飘带才有独立自由段。不要凭细长外观把拉链或固定装饰误作飘带；用户明确要求其飘动时按该设计调整。

- 悬垂带的上端或缝合段必须贴住衣服，固定段保持稳定，短过渡段衔接有间隙的自由段。不能仅将整条带刚性绑定胸骨、或整条向外移动，作为完成动态/连接的证据。
- 按位置和用户意图选择主要运动平面：胸前左右摆的带子以胸口局部左右方向为主，限制朝胸内运动与扭转；其他带子可使用不同方向。轴由实际模型坐标确定，不机械复制局部 Z 轴。
- 长带按长度分段并渐变权重，短硬扣件只绕真实挂点小幅转动。下方衣身表面完整；移除与带子重复的原始装饰几何，避免旧层仍在原位置闪烁。
- 先约定绑定、默认展示、关闭动态、重置和停跑后的姿态。默认下垂与“后伸再受重力下落”是不同设计；用户改为默认竖直时，同步修改几何、骨链轴向、按长度取权重的方法、运行力和 UI 文案，不沿用旧姿态测试。
- 借鉴尾巴只继承适用的根固定、分段和受力原则，不自动继承尾巴的弯曲外形、密集细分、回翘或水平绑定。带宽、数量、长度和接点由当前角色证据决定。
- 验收固定段实际贴合、自由段沿所选方向有可见运动、对禁止方向的位移受限；检查整条带的厚度与衣身/衣摆间隙，不只检查骨尖。左右摆动和回弹通过后，仍要单独检查起始端。

### 带状物返修边界

贴身环带记录宽厚、承载表面及闭合路径；松紧压痕只有明确参考/要求才做，取消压痕时恢复承载表面而保留环带位置。吊带按真实两端连接，不因环带重建而丢失。悬垂飘带记录折点、数量和末端；用户指定折线时用少数有意图的折点仿照走向，不自动替换为曲线，也不机械给所有角色使用折线。

## 验收与报告

检查阶段与复测范围由 [validation.md](validation.md) 决定；下面是相关专项的判断方法，不是每轮必跑清单。针对实际导出 GLB、实际蒙皮和运行时记录必要结果，不合并成笼统的“物理通过”：

1. **连接**：固定端几何接触承载物、运动中不脱离；骨骼父级与根顶点稳定另作检查。
2. **运动**：允许轴的响应非零且有限，受限轴符合设计；停止后收敛。静态部件检查保持稳定，不要求非零摆动。
3. **穿插**：同时运行头部、身体、四肢与附加动态，检查相关接触对；在正、侧、斜视下观察。数值采样说明动作、表面/端点范围和容差。
4. **闪烁**：检查重复几何、共面或近共面表面、缺失承载面及动态交替遮挡；无明显穿插不等于无闪烁。
5. **生命周期**：检查相关部件的扰动、停止、暂停恢复、关闭复位、重新启用、长停顿和瞬移及静止姿态约定；仅在 validation.md 的多帧率条件触发时扩展到 30/60/144 FPS。

已有测试若只验证挂点或骨尖，补充实际蒙皮固定段/自由段与可见接触检查后才能覆盖连接验收。测试阈值按角色尺度设定，不照搬本轮角色的绝对坐标、骨数或间隙。浏览器未观察的项目标 unverified；只报告已验证动作范围，不宣称所有姿态无穿模。


## 耳朵的像素造型范式

实际查看 [耳朵风格对照](../assets/part-style-kit/index.html)。外轮廓、壳体内凹、耳缘和内耳毛各有职责：外轮廓辨认耳型，内凹建立体积，耳缘控制壳厚，毛簇表达柔软。不要通过整体圆滑化、增加毛刺数量或加厚整耳替代这些结构。

- 圆耳/杯耳：在局部截面内建立有深度的碗面，后侧形成相应耳壳；正面保留凹腔负空间。体素格距沿用角色，轮廓台阶的节奏与头发一致，不做高密度锯齿。
- 尖耳：保留宽耳根和向尖端收束的轮廓，内耳形状随外壳缩进；不是圆耳拉长后贴一条颜色。尖端至少有可读厚度，避免单格长刺。
- 内耳毛：参考有毛时用少数宽毛簇沿生长方向叠起，根部接内壁，前端少量突出；留出上方凹腔，不把整个耳洞填白，不以等间距齿轮边模拟蓬松。
- 耳根—耳身—耳尖的体积连续。帽子遮耳时让遮挡成立，不靠增大耳朵或拉长耳根让其强行显露。两个耳朵的整体朝向可以不同，局部像素格仍各自一致。

具体构造可复用 [style-recipes.mjs](../assets/part-style-kit/style-recipes.mjs) 的 `ear({cupDepth,fur,pointed})` 与 `sample` 得到占用格，再交工程已有 mesher。示例尺寸是局部单位，不是角色默认比例；修改 cupDepth 不应改变外轮廓，添加 fur 不应扩大耳壳。几何本身不包含挂点、蒙皮或动态。

观察同色斜视仍能读出凹面，背面存在对应壳体，正常角色距离下毛簇仍是宽块而非噪点。结构读不出时先改壳体和留白，不继续加色条。
