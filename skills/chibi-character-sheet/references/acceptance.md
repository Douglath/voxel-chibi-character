# 视觉验收

每次生成或修改后都查看真实图像，不能仅凭提示词宣称通过。修订中优先检查改动项、关联结构与受影响视角，再快速确认无明显整体漂移；不逐轮重写五项报告。阶段完成时按下列五项全面视觉验收一次，记录 pass / fail / unverified 与简短观察。最终交付直接使用该最终图的验收记录，图未变不再检查；发现新问题或图像变更才复查。自动文件检查不代替视觉判断。

1. **母版**：Stage 2 对照同列头骨、眼线、下巴、肩腕、髋膝踝；排除发帽与鞋底外轮廓。衣服遮挡的关节标 unverified，不虚构精确坐标。检查眼框、脸宽、嘴部及身体尺度是否漂移。
2. **姿势相机**：四列顺序、第二列纯侧面和第四列偏转与母版一致；头胸骨盆脚同向关系正确，无镜像。Stage 1 用其自身四视图要求。
3. **身份与范围**：逐条比对身份锚点，服装裁片、鞋袜、配饰数目与挂点；无母版角色元素泄漏。双手与配件符合保留/排除清单，没有重新出现或改挂的排除道具。背面推定与可见结构兼容。
4. **三维结构**：头发先读大形后读层次，发束在正侧背一致；宽袖裙摆有开口厚度，鞋头和蝴蝶结结构成立，无悬浮或明显穿插。不可见细节不强称一致。
5. **材质版式**：柔和皮肤、克制结构面、无过度低模；背景、画幅、列位置与基线符合要求；无裁切、重叠、地面投影或多余文字。

明确的身份缺失、脸型/比例明显漂移、错误视角或连接矛盾是阻断项。遮挡本身不是失败，但可能影响后续建模，应记录推定和限制。仅 Stage 1 完成时 phase 为 concept，不能标 standardized。

修订默认每阶段不超过两轮；这是收敛边界，不是必须用满的生成次数。未通过则 status=needs_revision，列出可修问题。用户明确接受设计偏差后记录接受范围，不能把豁免写成视觉合格。
