## 证据支持到哪里

SU-001 审查定位到的主要缺口，是当时生成及验收规则没有把项目要求的静态直臂、方形近恒截面、手部容忍度落实为清楚的检查项。导入修复侧已经有更具体标准；不能说所有技能都没有规则，也不能用现在的文件倒推历史执行者一定读过它们。

设定图负责角色身份和服装设计，体素母版负责几何表达。柔和四视图本身不是失败；图片记录为 `ready/pass` 也不能认证模型风格。自然曲线可能促成照图制作低面数肢体，但未读取各生成会话的完整决策过程，不能把这一解释写成已证明的因果。

SU-001 已核对六份原始源码与下载包对应成员一致，并核对输入图与本地请求记录一致。本轮继承这些审计结论、回读指定源码和修订记录、查看并复制证据图，未重新做六份 ZIP 全量比对。现有证据不支持归因于下载改坏或云端版本不同。星熊保存的两份规则文档相同，也不等于整个历史技能包都经过版本审计。

## 人工复核原则

- 先确认角色形态和版本；`revision-v2` 这样的目录名不能代替版本记录。
- 在静态绑定姿态下看肩至腕中心线、局部截面及宽度变化；整体 A pose 倾斜、动画弯肘和宽袖都不是自动失败条件。
- 用相近显示尺度的正面和斜侧面与四图标尺对照。手部等级有不确定性时先补视角，临界边缘优先保留；不发明指头数量或数值百分比阈值。
- 改肢体后重新查袖口、手套、腕带的四面及受影响动作。风格可接受不能豁免露肤、缺面、漂浮或断接。
- 分别记录技术检查、可见效果、用户认可。本文“历史通过”只表示既有报告的结论。
