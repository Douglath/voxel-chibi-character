# 网页适配验收

1. 对实际静态/骨骼 GLB 构建并运行适用的 assets/baseline/test-*.mjs。新角色的部件或尺度变更要适配测试，不能套用旧报告。
2. 自包含 HTML 内嵌静态/骨骼文件、Three.js 与实际所需 JS 模块；模块数按当前模型统计，不固定为 10。确认没有外部模块导入、模型 fetch、CDN 或 /evidence 网络请求。源码注释中的网址不代表网络依赖。
3. 浏览器查看模型和基础动画、启动/停止跑动、暂停恢复、动态开关、掉落/跳下、结束复位；看正侧背及实际接触。WebGL报错应明确显示。
4. 检查 GLB 下载和 JSON 报告按钮。报告包含当前基础模型、生产头发动态和配件动态的测量，不代表全网格碰撞。保存的是基础骨骼 GLB，不会烘焙弹簧。有配件时检查其固定端、开孔、硬件保形与回弹；母版默认为空配件时不虚报配件动作已测。
5. 核对压缩包无绝对路径、无 node_modules、无密钥、无缺失资源；从解包项目重建。
6. 独立浏览器通过不等于在用户的网页版 ChatGPT 账号完成安装或内嵌预览测试。报告两者边界，遵守网页沙箱限制。
