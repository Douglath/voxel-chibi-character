# 分阶段生成约束

## Stage 1：角色设计翻译

目标：Japanese chibi stylized real-time game character，萌、精致、柔和、干净，有可信三维体积，适合后续建模。允许必要设计解释，不在此阶段强套固定素体。

提示词必须具体列出角色的发型轮廓、刘海分缝、马尾/辫子/特殊发束、发色、虹膜、头饰、服装类别与主要裁片、配色、鞋袜、标志配饰和图案。原图有的锚点不得因 Q 版化变成普通制服；不可见结构以最少假设补全，不增加身份装饰。双手空置；手持物若是唯一身份锚点，记录未展示原因，不将其擅自挂在身上。

头发少量宽大发束；衣服大裁片与少量结构褶皱；花纹刺绣文字作为表面图形。连接点合理，层次清晰，无悬浮配饰、穿模或融合。大型发束、蝴蝶结、鞋和硬配饰允许适量结构转折；脸、皮肤和主要布料柔和。避免粗糙低模、全身三角切面、PS1、voxel、方块四肢、棱角脸、写实人体材质。

输出横向单行四列：正面、角色左侧纯侧面（默认脸朝画面左）、正背面、角色左前方约 45°。同一设计、自然中立站姿、完整头顶至鞋底、双手空置、深色中性背景。无拆件、独立衣发配饰、道具栏、爆炸图、第二排、A/T-pose、文字和水印。

## Stage 2：固定母版换装

将固定母版作为编辑底图，不把概念图当底图再调比例。提示词开头写明：直接为底图中的同一个基础角色换装；仅替换指定的发型、服装、鞋袜、配饰、配色和眼睛内部设计。

冲突优先级：母版素体/头脸/表情 > 母版姿势/相机/尺度/版式/背景 > 角色设计锚点 > 替换部件的几何材质适配。

### 素体与面部

锁定头骨高宽深、后脑、脸宽颊体积、下颌、额头、眼线、上眼睑和眼框大小、眼距、鼻嘴和耳位、颈长、肩宽、躯干长、腰位、骨盆宽、四肢长短粗细、手脚尺寸及基础胖瘦。不得使角色更成熟、修长或纤细。

眼睛仅换虹膜颜色、瞳孔和内部图案，不扩大眼框或移动眼线。复制母版嘴部开合和表情，不继承原图笑容、圆眼或挑眉。

比较头骨、眼线、下巴、肩、肘、腕、髋、膝、踝之间的比例，头骨不含发帽，裸足身高不含鞋底。不得为容纳高帽缩小全身或为填满画面放大。衣服穿在母版身体上，宽袖不改肩臂，收腰不缩身体，裙长与高靴不改腿长。沿用脚底基线，鞋底变化只作必要位置调整。

### 头发

保留设计的长度、分缝、刘海方向、束发位置、主要卷曲、辫子和连接关系。先建立头顶/后脑/侧发/束发完整大体积，再划分少量主发束，必要处加次级层次。相邻同向细束合并；头顶后脑干净但不成为无分束头盔。

直发用有厚度的宽片/楔形，卷发用少量大弯曲和转折，辫子保留简明编织体块。厚而不鼓胀，避免管状软胶条、密集深槽、细刺、反复小 S 卷、逐层翻卷和精雕软塑料感。依靠叠压和侧面区分，不靠逐缕高光。允许柔和曲面和克制大面，不加假三角色块，不将所有发束做成尖锐多面体。不通过放大头骨容纳发型。

### 服装与配件

- 服装：保留裁片/领袖裙裤关系。领口袖口裙摆有边缘和内侧厚度；少量宽折面，层间清晰；小褶边合并为较宽折叠。花纹贴图表达，不做浮雕。布料不变纸片、盔甲、充气壳或密集软皱。
- 鞋：保留鞋款/鞋跟/配色/装饰；鞋头可读顶面、前面、侧面，短小倒角，鞋底与跟分层清晰。避免半球或胶囊鞋头、塑料高光；不把所有款式强改方鞋。
- 袜：贴腿处简洁，袜口少量宽折面、有厚度；无圈圈鼓包或改变腿粗细长度。
- 蝴蝶结：数量、大小关系、方向和连接点不变；结头独立、结翼宽折面、边缘有厚度、收束凹折清楚，带尾简洁；不变薄纸、枕头或厚硬板。
- 帽子/护目镜/圆饰：按母版对应材质和曲面处理，不因鞋服块面要求而额外粗化。金属、宝石、镜片保持材质差异。

### 材质、姿势与版式

匹配母版皮肤、头发、布料、鞋袜和配饰的粗糙度、高光、光向、曝光、白平衡、阴影和色彩。柔光保留结构方向，皮肤不额外加硬面；无写实微纹理或抛光玩具效果。

逐列复制母版头、胸、骨盆、脚朝向，手臂夹角、肘腕手指、腿间距；不根据角色性格改姿势。保留画幅比例、列中心、间距、身体尺度、脚底基线、相机高度、透视和留白。

顺序：FRONT、LEFT SIDE、BACK、FRONT THREE-QUARTER。这些是提示词中的视图名，不生成标签。第二列复制母版纯侧面朝向；第四列精确沿用母版偏转方向和幅度，不自动替换成 45°，不镜像、转背、只转头或增加侧转。

复制母版背景颜色、亮度与均匀程度，不依角色配色调背景；背景规则优先于母版可能存在的落地阴影：无实体地面、平台、地平线、落地投影或脚底阴影团，保留自身遮挡阴影。四视图全身完整不重叠，无额外角色、拆件、第二排、文字、水印。

## 提示词组装顺序

阶段/任务 → 各输入图的角色 → 具体身份锚点 → 本阶段不变量 → 部件几何材质规则 → 四列相机/姿势/背景 → 禁止项。Stage 1 不附带 Stage 2 素体锁定；Stage 2 每轮重申母版不变量。修订时明确指出哪一列哪一处错，保留已正确部件。不要把辅助例图误指定为换装目标。
