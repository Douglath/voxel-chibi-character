# 设定图适配与验证

## 建模前

建立部件表：ID、身份作用、外轮廓、配色、承载者、一个或多个挂点、路径、自身形变与独立运动、可见依据、推定及保留优先级。检查四列同一部件是否一致；透视遮挡不是新增或消失部件。保留非对称设计，以角色自身左右命名，不以画面左右直接代替。旧交接的 motion 仍可读取，在模型适配时结合部件类型转换，不要求重做旧设定图。

三维母版的尺寸和轴约定以底层实际文件为准。图片中的帽顶/发尖不能作为身体缩放依据。角色来源、输入哈希和有意简化项保存在角色 spec；未确认的推定不写成事实。

## 几何与颜色

- 主发束保留分组和连接，用经济大块表现轮廓；卷发/辫子概括主要转折与编织关系，不能退化为普通散发。
- 头发构建与配色读取底层 hair.md：保留宽侧发、鬓角与侧长发的结构区分；头顶覆盖发与前/侧/后发的接界衔接、内部宽发束的可读对比分别处理。不能为统一接界而压平整头层次，也不因增加配件而改回细条发束或自动提亮鬓发。具体发型、挑染分界和颜色依新角色参考。
- 服装保持层次和开口，必要运动接触面不删除；裙摆腰根稳定，宽袖给手腕留空间。碰撞问题先调整结构与动作范围，不能反折膝盖掩盖穿模。
- 服装可在同一裁片的已有折面、边缘和内外层使用低对比顶点色，增加部件内部体积；不只给相邻配件换色，不凭空增加装饰缝或厚块。保持主色和原有拓扑优先；新色界若使 greedy 合面分裂，按实际新增面/顶点记录成本。
- 发带/徽章等刚性饰品全顶点绑定同一挂点骨骼，随承载发束运动但不拉伸；下方头发连续有面。
- eyeWhite、eyeHighlight、iris 与服装颜色键分离，即使色值相同也不得共用可变用途键。需要虹膜静态明暗时，中部保留原 iris 基色，上部略暗、下部只轻微提亮，白色高光独立；不强制固定三行或改变眼形/表情。实际导出模型确认中部原色、分层克制和高光可见，不只检查调色板变量。
- 表面图案优先少量色块；底层一个顶点色材质目标不是删除身份图案的理由。确需纹理/额外材质时记录成本与原因，不默默改变整个管线。
- 组合配件按底层 accessories.md 映射构件和连接。先辨认缝合区、卡扣、穿孔与自由端，再填写当前角色尺度的实现坐标；描述中的“左肩”“胸前”不能直接充当数值挂点。硬件、贴身带和带尾各自选择形变与运动模式，多端固定物不自动套单根悬垂骨链。

## 动效

读取底层 dynamics.md 为选中部件设置挂点、限幅、刚度阻尼。保留基础 Idle 和关节测试；需要动态交付时提供角色转向/轻推以及适合的跑动演示。刚性中结/帽冠/鞋不软化。相机绕转不能代替角色本体扰动。

运行时附加链必须作用在预览加载的实际 GLB 骨架，不能只对另造的测试骨架通过。开始、暂停/恢复、停止并观察回弹、关闭/恢复动态均检查。根稳定，末端运动非零且有限，停止后收敛，瞬移和长停顿恢复不爆甩。按实际实现验证 30/60/144 FPS 响应；不能仅因数字有限而认定视觉自然。

## 有效验证

1. 构建后回读实际 GLB，检查网格/骨骼/片段，实测三角面、顶点、材质、网格数、骨骼及活动粒子；draw calls 从实际运行渲染统计读取。
2. 比对正侧背斜视与设定图身份清单。用中立姿势比外观，用 T-pose 和关节动作验绑定，分开记录。正常预览距离检查标志配件的轮廓/主色与连接关系；局部近景检查开孔、厚度、固定端与硬件保形。细节过小时优先概括，不能放大所有小件导致比例失真。
3. 运行相关几何/膝盖/裙袖/挂点/动态测试；适配部件名和采样点，不删断言追求全绿。颜色或饰品小改仅复测受影响项，骨架和基础几何改动再扩大检查。
4. 浏览器验证真实预览、动作切换、暂停恢复和回弹并保存截图。无法使用浏览器时注明数值已测、可视交互未测，不能报完整验收通过。
5. 衣发碰撞只报告测试动作与采样范围，不扩大为完整自碰撞保证。原地跑动无足底锁定时明确限制。

这些要求是每个新角色制作时执行的验收，不要求为安装本 skill 而批量重新生成角色。
