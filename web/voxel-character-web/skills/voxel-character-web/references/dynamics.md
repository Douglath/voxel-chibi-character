# 动态选择、强度与成本

除明确静态/禁用动画外，默认基础动画与合适的附加动态。默认选 2–3 类、约 4–8 新骨；用户明确完整精修时逐项覆盖合理活动部件。母版 20 基础骨 + 23 附加骨只是当前实例，不是每个角色配额。不添加参考里不存在的部件来用满预算。

## 当前范例参数

以下仅用于同尺度、同公式的起点；角度是上限，不是目标摆幅。

| 部件 | 刚度/阻尼 | 限角与结构 |
|---|---|---|
| 后发 | 左 62/11、右 68/12 | .24 rad；每侧两骨，根稳末端滞后 |
| 鬓发/侧发 | 165/22，辅助外发 95/15 | .075/.12 rad；连续发片共享兼容权重 |
| 耳朵 | 290/30 | .025 rad；每耳整体刚性微转 |
| 侧衣摆/后衣摆 | 130/19、155/21 | .08/.06 rad；腰部承载 |
| 袖下缘 | 125/19 | .075 rad；跟随前臂，非整袖软化 |
| 胸口飘带 | 105/17 | .14 rad；两骨、胸前左右平面摆动 |
| 尾巴 | 见 tail-dynamics.mjs | 三段重力角弹簧，骨盆尾根固定 |

短扣件、中结、帽冠、鞋、脸通常刚性。柔长发、布条、挺括耳饰应有不同响应；不全用同频正弦。参数和轴按实际结构修改，不照抄到帽子、辫子或披风。附加骨必须实际影响几何，不能只生成空骨。

## 稳定性与成本

- 固定步进 1/120 秒、限角、阻尼、长停顿/瞬移重置。模拟端也约束方向，骨骼转速受限；详见 drop-testing.md。运行时有重复矩阵更新和临时分配，不声称多角色已优化。
- 先减少无收益链，再实测投影次数与分配优化。几何发束合并不会自动减少骨骼或模拟成本。
- 关闭附加动态停止积分，显示约定的静止姿态；基础动画与 GPU 蒙皮仍存在。真正静态版要移除皮肤/骨架。远景简化建议不代表已实现自动 LOD。
- 区分静态 GLB 与带骨骼/基础片段 GLB的差值、附加运行代码体积、CPU模拟、GPU蒙皮、绘制次数。物理关闭不减少下载体积。耗时只报告具体设备/环境实测，不将 Node CPU 测试当浏览器帧率保证。
- 母版仅局部端点/胶囊与角度约束；不是完整头发、衣服自碰撞。脚底没有 IK。
- 本坐标正面 +Z，小腿局部 +X 屈曲使足跟后移；其他骨轴需实际检查。跑动展示不等于成品步行动作。

一轮处理一个明确问题，先造型连接后动态。相机环绕不等于角色受力，拖动演示须改变角色变换。测试实际 GLB 与生产代码，范围见 validation.md。
